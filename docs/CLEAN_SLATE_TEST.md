## 6. ما يجب إصلاحه قبل الإطلاق

1. **JDK محمول تلقائياً** داخل `%LOCALAPPDATA%\FlutterWay` بدل الاعتماد على winget/UAC.
2. **مهلة `flutter create` 600 ثانية** + حفظ stdout/stderr وإظهاره عند الفشل.
3. **زر إعادة المحاولة** يُعطّل أثناء `setup_running` أو يعرض «انتظر…».
4. **سطح خطأ قابل للقراءة** بدل «راجع سجل الأخطاء».
5. **تقدّم متدرّج** + فصل نسبة المرحلة عن النسبة الكلية (ملاحظة المستخدم).
6. **توقّع زمني** لأول بناء: «أول بناء قد يأخذ 10–20 دقيقة» قبل الضغط.

- **المسار السعيد يعمل** بعد تجاوز JDK و`flutter create`.
