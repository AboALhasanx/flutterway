## 1. التشغيل

```powershell
python tests/reliability_faults.py
python tests/test_build_guard.py
python tests/test_pnp_filter.py
python tests/audit_smoke.py
python tests/student_journey.py
```

- `reliability_faults.py` — 36 فحصاً في Chromium مع جسر pywebview وهمي؛ **بدون جهاز وبدون بناء حقيقي**.
- `test_build_guard.py` — يمنع بناءين/تجهيزين متزامنين في الباك إند.
- `test_pnp_filter.py` — يمنع تنبيه تعريف USB الكاذب.
- `audit_smoke.py` — ثوابت وواجهة.
- `student_journey.py` — رحلة UI حقيقية.

## 3. أعطال اكتُشفت وأُصلحت

| # | العطل | قبل | بعد |
|---|---|---|---|
| R-01 | زر «ابدأ البناء» يظهر بعد النجاح | دوامة إعادة بناء + بطاقة قديمة | مخفي في حالة `success` |
| R-02 | polling الهاتف يعيد الزر | الزر يرجع كل 5 ثوانٍ | لا يظهر إلا في `idle/failed` |
| R-03 | إعادة المحاولة لا تصفّر الحالة | خطوة 3 حمراء + مؤقت 00:00 | `resetBuildUi()` تصفّر الكل |
| R-04 | بناءان متزامنان | 2 threads بلا قفل | `build_running` guard |
| R-05 | تجهيزان متزامنان | 2 workers | `setup_running` guard |
| R-06 | فشل إنشاء مشروع | «تم الإنشاء بنجاح!» + `undefined` | رسالة خطأ + لا تغيير للنشط |
| R-07 | فشل تنظيف المشروع | «تم تنظيف الكاش!» | رسالة خطأ + استرجاع الزر |
| R-08 | فشل إصلاح Doctor | «تم الإصلاح بنجاح!» | رسالة خطأ في الملخص |
| R-09 | فشل فحص اللابتوب | زر «جاري الفحص...» للأبد | صندوق خطأ + «أعد المحاولة» |
| R-10 | فشل drivers/ADB | زر «جاري...» للأبد | رسالة فشل + استرجاع |
| R-11 | فشل فتح VS Code | صامت | حالة خطأ أسفل المشروع |
| R-12 | تنبيه تعريف USB كاذب | أي `OtherDevices` = أندرويد | Android/ADB فقط + فلتر Python |
| R-13 | فشل تحميل المشاريع | صامت | حالة خطأ + إعادة محاولة |
| R-14 | Hot Reload بلا APK | فشل فوري برسالة مخفية | يبني تلقائياً `flutter run` (106 ثانية أول مرة) |
| R-15 | APK غير موقّع بعد البناء التلقائي | إعادة بناء كل مرة | يحسّن `app-debug.apk` تلقائياً → **19.1 ثانية** |
| R-16 | خطأ Hot Reload مخفي في السجل | المستخدم لا يعرف السبب | يظهر في `hr-quick-hint` الأحمر |
| R-17 | زر "جرّب Hot Reload" من الرئيسية | يفتح التبويب فقط | يبدأ الجلسة تلقائياً |

## 5. قيود الجلسة الحالية

- لم تُجرَ اختبارات فصل الكيبل أثناء البناء أو رفض التصحيح.
