1. التحديث الفوري Hot Reload مقابل Restart
• Ctrl + S أو r: يحدّث واجهة الشاشة بأجزاء من الثانية دون فقدان حالة التطبيق.
• R (كبيرة): يعيد تشغيل التطبيق بالكامل إذا قمت بتغيير دالة main أو initState.
2. مفتاح الحل السحري في VS Code (Ctrl + .)
قف على أي ويدجت واضغط Ctrl + . لتغليفها داخل Padding أو Center أو Row أو استخراجها في دالة بلمح البصر!
3. متى تختار StatelessWidget ومتى StatefulWidget؟
• Stateless: لشاشة أو عنصر ثابت لا يتغير نصه أو حالته (مثل شاشة حول التطبيق).
• Stateful: إذا كان هناك عداد، زر، حقل كتابة، أو بيانات تتغير على الشاشة.
4. القاعدة الذهبية لتفادي أخطاء الجرادل وبطء البناء
• أبقِ الكيبل موصولاً دوماً وثابتاً أثناء البناء.
• لا تقم بإنشاء مشاريع في مسارات تحتوي على أحرف عربية (مثل مجلد "سطح المكتب").

تم تثبيت فلاتر وضبط المحرر وإنشاء مشروعك الأول. إليك كيف تبدأ العمل في VS Code:
1. مشروعك مفتوح وجاهز

2. أبقِ هاتفك متصلاً بالكيبل
تأكد من بقاء الكيبل موصولاً حتى يتم إرسال التطبيق لشاشة هاتفك فوراً.
3. زر التشغيل السحري F5
اضغط F5 في الكيبورد لتشغيل وبناء التطبيق وإرساله لشاشة الهاتف.
4. التحديث الفوري Hot Reload
عدّل أي نص في ملف (lib/main.dart) واضغط Ctrl+S؛ يتغير الهاتف بثانية!

اضغط الفحص لمعاينة الملفات قبل الحذف
⚠️ هذه الأدوات للمطور فقط. الحذف نهائي. مسارات C:\flutter و C:\Android و C:\g لا تُحذف إلا بعد كتابة DELETE.
1. واجهة الطالب فقط
ترجع الواجهة للمستوى 1 وتصفّر التقدم والأخطاء بدون لمس أي ملف.
2. مشاريع الاختبار
يحذف my_first_app ومشاريع المحاضرات وسجل المشاريع الحديثة.
3. تحميلات FlutterWay
يحذف Flutter/JDK/Android SDK/Gradle الموجودين تحت LOCALAPPDATA فقط.
4. التحميلات القديمة
يحذف C:\flutter و C:\Android و C:\g أيضاً. يتطلب تأكيد DELETE.
5. PATH والبيئة
يزيل مسارات Flutter/JDK/SDK ومتغيرات JAVA_HOME وANDROID_HOME مع نسخة احتياطية.
6. إعدادات VS Code
يزيل مفاتيح dart.* فقط. يمكنك أيضاً حذف إضافتي Flutter/Dart لإعادة اختبار تثبيتهما.
7. تطبيقات الهاتف
يلغي تثبيت com.example.flutter_test_app وcom.university.flutterway.* من الأجهزة المتصلة.
8. كاش البناء
يحذف build و.dart_tool من المشاريع فقط، لإعادة تجربة زمن البناء.
9. JDK النظامي
يحذف Eclipse Adoptium JDK 21 من Program Files عبر winget لاختبار تنزيله من جديد. يتطلب DELETE.
10. مسح شامل (كل ما سبق)
الهاتف + المشاريع + PATH + VS Code + التحميلات. عند تفعيل الخيار: مسارات C:\flutter و C:\Android و C:\g، وإضافات VS Code، وJDK أيضاً.
